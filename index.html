Choose fine-tuning tools after defining the target behavior

Clarify whether the task needs model adaptation, preference training, data preparation, distillation or packaging an already trained model. These catalog roles overlap but their outcomes are not interchangeable.

Guide sources reviewed 2026-11-03. Catalog snapshot: 2026-11-06T17:25:27.023153+00:00. Source review does not mean runtime testing.

Adapt a model

Confirm support for the exact base model, data format and training method. Document hardware, checkpoint and reproducibility constraints before starting.

Current catalog categories: PEFT & LoRA; Fine-Tuning Tools; Training Frameworks.

Change behavior using feedback or examples

Define the desired behavior and reviewed data. Keep a held-out evaluation set and check regressions beyond the targeted examples.

Current catalog categories: RLHF & Preference; Training Data.

Prepare an adapted model for use

Distinguish distillation, weight merging and quantization. Verify the resulting artifact in the inference runtime you will use.

Current catalog categories: Distillation; Quantize & Merge.

Evidence to check before choosing

  • Check base-model, training-data and tool licenses from their separate sources.
  • Record the full recipe and compare held-out task behavior against an unchanged baseline.
  • Verify checkpoint export and inference compatibility rather than assuming successful training is sufficient.
